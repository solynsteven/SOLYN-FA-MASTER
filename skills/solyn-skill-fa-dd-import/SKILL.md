# solyn-skill-fa-dd-import

## 执行方式（混合）

1. **确定性解析（默认）**：`src/skills/index.ts → ddImport` + `src/lib/import/engine.ts`。
2. **Claude 兜底**：表头无法确定性匹配且配置了 Anthropic Key 时，把未匹配表头与可用字段交给 Claude，本文件作为 system prompt，只返回 JSON 映射。

## 模板结构（List v5，材料前缀编码版）

工作簿只有一个工作表「資料依頼リスト」：第 1–2 行为标题与版本说明（从 B 列开始），第 3 行表头，第 4 行起数据，全 96 项 / 9 分类。

### 列 → 字段

| 列 | Excel 表头 | 字段 key | 类型 | 语义角色 | 说明 |
|---|---|---|---|---|---|
| A | 材料前缀编码 | prefix_code | 文本（存库型计算） | 编号 | **匹配键 + 排序索引**。`=CONCATENATE(B,"-",D,"-",E,"-",两位F)`，如 `S1-Bas-Adm-01`。系统按 B/D/E/F 重新计算，忽略文件值 |
| B | 分类编码 | cat_code | 下拉 | — | S1 … S9，与 C 列一一对应 |
| C | 材料分类名称 | category | 下拉 | 种类 | 中日双语换行：`1. 公司基本·组织\n1. 会社基礎・組織` |
| D | 大类代码 | major_code | 文本 | — | Bas / Fin / Biz / Ass / HR / Leg / IT / Deal / Inds |
| E | 中类代码 | minor_code | 文本 | — | Adm / Acct / Tax / Org / Sala / Hum … |
| F | 顺序码 | seq | 数字 | — | 首行为 1，其后 `=IF(E本行=E上行, F上行+1, 1)`；取公式缓存值，缺失时按同一规则补全 |

| J | 提出状态／提出ステータス | status | 下拉 | 状态 | 见下 |
| K | 请求日／依頼日 | request_date | 日期 | 开始日期 | |
| L | 接收日／受領日 | received_date | 日期 | — | |
| M | 提供者·担当 | provider | 文本 | 负责人 | |
| N | 保存位置·文件名 | location | 文本 | — | |

旧版（带 No. 列、「材料前缀编码 = 大类-中类」）的表头别名仍可识别：大分类／大分類 → 材料分类名称，大类编码 → 大类代码，中类编码 → 中类代码。

### 提出状态（J 列下拉）

`未请求／未依頼`、`已请求／依頼済`、`部分接收／一部受領`、`已接收／受領済`、`不适用／該当なし`

- 完成：`已接收／受領済`；`部分接收` 计为未完成；不计入分母：`不适用／該当なし`
- **完成率 = 已接收 ÷（项目数 − 不适用）**

### 版本标记（P 列）

| 底纹 | 文字 | 含义 |
|---|---|---|
| 蓝 `D9E2F3` | 内容改訂 v3／v3修订 | v3 内容修订 |
| 橙 `FCE4D6` | 新規追加 v4／v4新增 | v4 新增：雇佣司机劳务 |
| 绿 `E2EFDA` | （空） | v3 新增：出租车业专项 → **按底纹补全为「新規追加 v3／v3新增」** |

## 解析规则

1. 工作表：优先「資料依頼リスト」，否则按表头关键词得分选择；表头行取前 20 行中命中关键词最多的一行。
2. 表头匹配：字段名全等 → 别名全等 → 近似 → Claude。
3. 数据行：资料名称非空即为数据行；顺序码缺失时按上行补全；再计算材料前缀编码。
4. 材料前缀编码无法生成（B/D/E 缺失）的行跳过并提示；重复编码仅保留第一条。

## 差异与写入

- 按材料前缀编码比对；合并 / 完全同步两种模式；默认空单元格不覆盖；未知下拉值可自动加入选项。
- 每条新增、修改、删除都写入变更日志（含删除日期），`source = import`。
- 网站手工新增时：顺序码可留空，系统取同组（分类编码 + 大类 + 中类）下一个号；分类名称可由分类编码自动带出；编码不得重复。

## Claude 映射输出格式

仅输出 JSON：

```json
{"mappings":[{"col":6,"fieldKey":"seq"}]}
```

中日同义参考：依頼日 = 请求日；受領日 = 接收日；担当 = 负责人 / 提供者；備考 = 备注；改訂 = 变更；顺序号 = 顺序码。无法确定给 `null`。
