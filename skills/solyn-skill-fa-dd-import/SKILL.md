# solyn-skill-fa-dd-import

## 执行方式（混合）

1. **确定性解析（默认）**：`src/skills/index.ts → ddImport` + `src/lib/import/engine.ts`。
2. **Claude 兜底**：表头无法确定性匹配且配置了 Anthropic Key 时，把未匹配表头与可用字段交给 Claude，本文件作为 system prompt，只返回 JSON 映射。

## 模板结构（List v5，中日合并表记版）

工作簿包含 4 个工作表，**只导入「資料依頼リスト」**：

| 工作表 | 用途 | 导入 |
|---|---|---|
| 使用説明・凡例 | 使用说明、图例、三大风险、出租车业论点 | 否（参考） |
| 資料依頼リスト | 主表：全 96 项 / 9 大类 | **是** |
| 進捗サマリー | 公式自动汇总看板 | 否（网站自行统计） |
| 社長面談 質問リスト | 社长面谈提问清单 | 否 |

主表：第 1–2 行为标题与版本说明，第 3 行表头，第 4 行起数据。

### 列 → 字段

### 提出状态（I 列下拉）

`未请求／未依頼`、`已请求／依頼済`、`部分接收／一部受領`、`已接收／受領済`、`不适用／該当なし`

- 完成：`已接收／受領済`；`部分接收` 计为未完成
- 不计入分母：`不适用／該当なし`
- **完成率 = 已接收 ÷（项目数 − 不适用）**，与「進捗サマリー」口径一致

### 版本标记（O 列）

| 底纹 | 文字 | 含义 |
|---|---|---|
| 蓝 `D9E2F3` | 内容改訂 v3／v3修订 | v3 内容修订（No.27–36、42） |
| 橙 `FCE4D6` | 新規追加 v4／v4新增 | v4 新增：雇佣司机劳务（No.83–96） |
| 绿 `E2EFDA` | （空） | v3 新增：出租车业专项（No.75–82）→ **按底纹补全为「新規追加 v3／v3新增」** |

## 解析规则

1. 工作表：优先名为「資料依頼リスト」的工作表，否则按表头关键词得分选择。
2. 表头行：前 20 行中命中关键词最多的一行（No. / 资料名称 / 必要度 / 提出状态 …）。
3. 表头匹配：字段名全等 → 别名全等（如「资料名称」「資料名」）→ 近似 → Claude。
4. 数据行：`No.` 与 `资料名称` 均非空才算数据行；重复 No. 仅保留第一条并提示。
5. 取值：公式取缓存值；日期转 `YYYY-MM-DD`；文本保留换行（中日双语）。

## 差异与写入

与 FA 导入相同：按 No. 比对；合并 / 完全同步两种模式；默认空单元格不覆盖；未知下拉值可自动加入选项；每条新增、修改、删除都写入变更日志（含删除日期），`source = import`。

## Claude 映射输出格式

仅输出 JSON：

```json
{"mappings":[{"col":10,"fieldKey":"request_date"}]}
```

中日同义参考：依頼日 = 请求日；受領日 = 接收日；担当 = 负责人 / 提供者；備考 = 备注；改訂 = 变更。无法确定给 `null`。
